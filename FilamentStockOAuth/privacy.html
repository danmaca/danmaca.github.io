Privacy Policy

Last updated: October 29, 2026

This policy describes how Filament Stock, a personal inventory of 3D-printing filaments made by Daniel Macek, handles the data it receives from Google. The application runs on its owner's own computer and is used only by its owner; it is not a public service.

Google user data the application accesses

Google Drive is connected only when the owner chooses to (Connect Google Drive). The application then asks only for the permission https://www.googleapis.com/auth/drive.file and accesses:

  • the e-mail address of the connected Google account,
  • the folder chosen in the Google Drive folder picker (its identifier and name),
  • the backup files the application uploaded to that folder (their identifiers and names),
  • the access and refresh tokens issued by Google.

Because of the drive.file permission the application cannot see or read any other files or folders in the Google Drive.

How the data is used

  • The backup files of the application's database are uploaded to the chosen folder.
  • The folder is listed to find out which backups are uploaded already.
  • The application's own older automatic backups are moved to the Google Drive trash, so that only the configured number of them is kept. Other files are never changed or deleted.
  • The e-mail address and the folder name are shown on the maintenance page of the application, so that the owner sees where the backups go.

The data is used for nothing else: it is not used for advertising, it is not sold, and it is not used to develop, improve or train generalized artificial intelligence or machine learning models.

Storage and protection

The account e-mail, the folder and the tokens are stored only on the computer that runs the application, in a file of the application's storage; the tokens are encrypted (ASP.NET Core Data Protection). They are not stored in the database and are not part of the backups. All communication with Google uses HTTPS. The uploaded backups are stored by Google in the owner's Google Drive.

Sharing

The data received from Google is not shared, transferred or disclosed to any third party.

Retention and deletion

  • The stored Google data is kept until Google Drive is disconnected. The Disconnect button of the application revokes the access at Google and deletes all the stored Google data.
  • The access can also be revoked in the Google Account settings; the application then discards its token the next time Google refuses it, and Disconnect deletes the remaining connection details.
  • The backup files uploaded to Google Drive stay there until the owner deletes them in Google Drive.

Google API Services User Data Policy

Filament Stock's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

When the policy changes, the new version is published on this page with a new date.
